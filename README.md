# Little Planet Academy Website

Sophisticated multi-page school website (redesigned in the elegant style of Uncle D Grand Events).

## Pages

- `index.html` — Home (hero, pathways, about preview, CTA)
- `academics.html` — Sections & curriculum
- `about.html` — About the school
- `gallery.html` — Photos (all 8 images)
- `contact.html` — Phone, WhatsApp, address + **live Google Map**

## Shared files

- `styles.css` — Full modern styles (Cormorant Garamond + Montserrat, navy/gold palette)
- `script.js` — Working hamburger menu with overlay + navbar scroll effect
- `images/` folder (must stay next to the HTML files)

## Deploy (Vercel / GitHub Pages / Netlify)

1. Extract the zip
2. Upload the **entire folder** (all HTML + CSS + JS + `images/`)
3. Do not upload only `index.html` — pictures and other pages will break

Keep this structure:

```
folder/
├── index.html
├── academics.html
├── about.html
├── gallery.html
├── contact.html
├── styles.css
├── script.js
├── README.md
└── images/
```
